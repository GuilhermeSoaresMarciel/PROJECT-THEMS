# PROJECT-THEMS

Este site foi desenvolvido para se adaptar ao horário do dia, exibindo um tema que combine com diferentes períodos, como manhã, tarde e noite. Para isso, foram utilizados html, CSS e JavaScript.

O principal método que tornou essa funcionalidade possível foi o `Date`, que permitiu obter informações sobre a data e o horário atual. Com esses dados, o Web App consegue identificar o período do dia e, automaticamente, decidir qual tema deverá ser exibido.
